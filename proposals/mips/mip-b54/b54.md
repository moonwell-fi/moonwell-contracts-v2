# MIP-B54: MetaMorpho Vault Incentive Campaigns

### **Summary**

This proposal creates xWELL incentive campaigns for four MetaMorpho vaults on
Base (USDC, WETH, EURC, and cbBTC), maintaining the same APY as MIP-X40. The
campaign starts exactly when the X40 incentive campaigns end and runs until
February 2nd, 2026. The meUSDC vault is excluded from this incentive round.

### **Background**

Moonwell's MetaMorpho vaults provide optimized lending yields by depositing into
Morpho Blue markets. To attract liquidity and maintain competitive yields, the
protocol distributes xWELL token incentives to vault depositors via Merkle
campaigns.

MIP-X40 established a 14-day incentive structure for these vaults. This proposal
continues those incentives seamlessly with the same reward rate (APY), starting
immediately when X40 ends and running until February 2nd.

### **APY Calculation**

To maintain the same APY as MIP-X40:

- **X40 vault duration:** 1,209,600 seconds (14 days)
- **B54 duration:** 1,420,182 seconds (~16.44 days)
- **Duration ratio:** B54/X40 = 1,420,182 / 1,209,600 ≈ 1.174
- **Formula:** `new_amount = x40_amount * (new_duration / x40_duration)`

This ensures depositors receive the same reward rate per second, maintaining
consistent APY despite the different campaign duration.

### **Proposal Actions**

1. Bridge xWELL tokens from Moonbeam to Base via Wormhole
2. Approve Merkle Campaign Creator to spend xWELL
3. Accept Merkle campaign conditions
4. Create individual campaigns for each vault:
   - USDC MetaMorpho Vault campaign
   - WETH MetaMorpho Vault campaign
   - EURC MetaMorpho Vault campaign
   - cbBTC MetaMorpho Vault campaign

### **Rationale**

Continuing vault incentives maintains liquidity in Moonwell's MetaMorpho vaults
and provides competitive yields for depositors. By starting exactly when X40
ends with the same APY, users experience seamless, uninterrupted rewards.

Excluding meUSDC allows the protocol to focus incentives on the core vaults
while the meUSDC strategy is evaluated separately.
