# MIP-X69: Anthias Labs Risk Parameter Recommendations (9/29/26)

## Summary

This proposal implements Anthias Labs' September 29, 2026 risk parameter
recommendations for Moonwell Core markets on Base and OP Mainnet.

## Base

### Risk Parameter Changes

| Market  | Parameter         | Current | Proposed |
| ------- | ----------------- | ------: | -------: |
| WELL    | Collateral Factor |     55% |      45% |
| MORPHO  | Collateral Factor |     60% |      40% |
| VIRTUAL | Collateral Factor |     65% |      55% |
| wrsETH  | Collateral Factor |     46% |      42% |
| cbBTC   | Reserve Factor    |     10% |      99% |
| MAMO    | Collateral Factor |     50% |       0% |

### cbBTC Interest Rate Model

| Parameter       | Current | Proposed |
| --------------- | ------: | -------: |
| Base            |       0 |     0.01 |
| Kink            |     0.8 |        0 |
| Multiplier      |  0.0615 |        0 |
| Jump Multiplier |       5 |        0 |

The proposed model targets a simple annual borrow rate of 1% at any utilization.
With a 99% reserve factor, 99% of interest accrual is allocated to reserves.

## OP Mainnet

| ------ | ----------------- | ------: | -------: |

| OP     | Collateral Factor |     65% |      60% |
