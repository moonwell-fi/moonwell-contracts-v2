# MIP-X51B: Monthly Rewards Distribution — Base + Bad-Debt Repayments

Split from MIP-X51 to fit Moonbeam's per-extrinsic gas ceiling. This half covers
Base chain reward updates and the four bad-debt repayments from the original
MIP-X51.

Moonbeam and Optimism reward updates ship separately as **MIP-X51A**.

## Scope

### Base rewards (delivered via one Wormhole `publishMessage`)

- 38 setMRDSpeeds updates across Base markets
- 1 transferFrom for reward top-up
- 1 withdrawWell
- 5 merkleCampaigns

## Motivation

Same as MIP-X51A: the original MIP-X51 propose() was 36.2M gas and could not be
submitted through any public Moonbeam RPC, nor would Substrate collators include
an extrinsic of that declared weight. Splitting along chain-destination
preserves all behaviour and only changes the governance bundling.
