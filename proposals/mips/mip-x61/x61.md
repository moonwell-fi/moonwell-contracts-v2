# MIP-X61: Anthias Labs Monthly Risk Parameter & Reserve Recommendations (7/2026)

## Summary

This proposal seeks to implement the following parameter changes to Moonwell's
Core markets on Base. Additionally, this proposal takes action to address the
protocol's outstanding bad debt while continuing remediation efforts for users
affected by the cbETH incident. It also updates the supply and borrow cap
guardian on Ethereum to the Anthias multisig.

## Bad Debt Repayment

We recommend that the protocol use its reserves to repay the bad debt on behalf
of the following addresses. These addresses are currently supplying no
collateral, which means their debt positions can be safely repaid without risk
to the protocol. This action will help recapitalize the affected markets. The
total bad debt repayment for this proposal amounts to approximately $35,000.
