# MIP-X75: Anthias Labs Risk Parameter Recommendations (10/27/26)

## Summary

This proposal implements Anthias Labs' October 27, 2026 risk parameter
recommendations for Moonwell Core markets on Base and OP Mainnet, continuing the
collateral factor wind-down for AERO, WELL and MORPHO on Base and for VELO, OP
and wrsETH on OP Mainnet. It also replaces the deprecated MAMO / USD price feed
on Base with a fixed price of $0.01.

## Base

### Risk Parameter Changes

| Market | Parameter         | Current | Proposed |
| ------ | ----------------- | ------: | -------: |
| AERO   | Collateral Factor |     58% |      55% |
| WELL   | Collateral Factor |     35% |      20% |
| MORPHO | Collateral Factor |     40% |      30% |

### Oracle Changes

| Market | Current              | Proposed          |
| ------ | -------------------- | ----------------: |
| MAMO   | Chainlink MAMO / USD | Fixed price $0.01 |

Chainlink is deprecating the MAMO / USD feed. MAMO's collateral factor is already
0%, so the price only affects MAMO borrowers. The only active position is
[0x81f6…1b3f](https://risk.anthias.xyz/moonwell/core/base/wallets?address=0x81f6ae5bd24a31b0b28ffb4012e34d6a10761b3f)
($38.9K USDC supplied, 1.39M MAMO borrowed), which would become liquidatable
only above $0.0247. At $0.01 it sits at a health factor of about 2.5. Setting
the price slightly above the last answer avoids undervaluing MAMO debt, and it
keeps liquidations of MAMO debt profitable until MAMO trades about 65% above its
last price. A future governance proposal can change the fixed price if needed.
