# MIP-X55: Recognizing WELL on Ethereum

## Summary

This proposal connects Ethereum mainnet to the existing `xWELL` bridge system.

Today, WELL can already move between Moonbeam, Base, and Optimism. However,
Ethereum mainnet is not yet fully connected to that bridge network. This
proposal updates the bridge adapters on Moonbeam, Base, and Optimism so they
recognize Ethereum as an approved bridge source and destination.

Upon proposal completion, users will be able to bridge WELL between Ethereum
mainnet and the existing supported chains.

This proposal does not move any tokens, upgrade any contracts, or change bridge
rate limits. It only updates the bridge configuration needed for Ethereum to
join the existing token's bridge mesh.

## Background

`xWELL` has been deployed on Ethereum mainnet at the following address:

`0xA88594D404727625A9437C3f886C7643872296AE`

The Ethereum `WormholeBridgeAdapter` has also been deployed at:

`0x734AbBCe07679C9A6B4Fe3bC16325e028fA6DbB7`

However, the existing bridge adapters on Moonbeam, Base, and Optimism do not yet
recognize the Ethereum adapter. As a result, bridge messages coming from
Ethereum would currently be rejected, and bridge transfers from the existing
chains back to Ethereum would not have a valid Ethereum destination configured.

MIP-X55 prepares the existing chains to accept and send `xWELL` bridge transfers
involving Ethereum mainnet.

This is also an important step before MIP-X57 or MIP-X5X, which is expected to
migrate Moonwell governance to Ethereum and rely on `xWELL` voting power across
all supported chains.

## Proposal

This proposal updates the `xWELL` bridge adapters on Moonbeam, Base, and
Optimism.

For each chain, the proposal makes two configuration changes:

1. **Adds Ethereum as a trusted sender**

   This allows the local bridge adapter to accept valid `xWELL` bridge messages
   that come from the Ethereum bridge adapter.

2. **Sets Ethereum as an outbound bridge destination**

   This allows users to bridge `xWELL` from Moonbeam, Base, or Optimism back to
   Ethereum mainnet.

The Ethereum bridge adapter used for each chain is:

| Wormhole Chain ID | Ethereum Bridge Adapter                      |
| ----------------- | -------------------------------------------- |
| 2                 | `0x734AbBCe07679C9A6B4Fe3bC16325e028fA6DbB7` |

The proposal is executed through the Moonbeam `MultichainGovernor`.

Moonbeam actions are executed directly. Base and Optimism actions are delivered
through Wormhole to each chain’s `TemporalGovernor`.

## Rationale

Ethereum mainnet access is an important milestone for the WELL ecosystem because
it connects WELL to the largest and most widely used smart contract network. By
enabling users to bridge WELL between Ethereum, Moonbeam, Base, and Optimism,
Moonwell can make WELL governance and participation more accessible to a broader
set of users, investors, and ecosystem partners. This also lays the groundwork
for future Ethereum-based governance infrastructure, including MIP-X57 or
possibly MIP-X5X, which is expected to rely on xWELL voting power across all
supported chains.
