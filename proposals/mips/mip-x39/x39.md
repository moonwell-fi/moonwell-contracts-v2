# MIP-X39: Remove configureAsset from stkWELL

## Summary

This proposal upgrades the stkWELL (Staked WELL) implementation on all three
chains - Base, Optimism, and Moonbeam - to remove the `configureAsset` function
due to security concerns.

## Motivation

The `configureAsset` function in the stkWELL contract's DistributionManager has
been identified as having a security vulnerability. This function is only used
for initial configuration and is not needed for ongoing operations. Removing it
reduces the attack surface while maintaining all existing functionality.

## Technical Details

### Changes Made

1. **Removed `configureAsset` function** from:

   - `DistributionManager.sol` (implementation)
   - `IDistributionManager.sol` (interface)

2. **Updated interfaces** in moonwell-contracts-v2:
   - `src/IStakedWell.sol`
   - `src/interfaces/IStakedWellUplift.sol`

### What's Preserved

- The `configureAssets` (batch version with array inputs) function remains
  available
- All existing staking functionality continues to work
- User balances, voting power, and total supply are preserved
- Staked token, rewards vault, and emission manager references remain unchanged

- Moonbeam uses `StakedWellMoonbeam.json` (uses `block.number` for voting
  snapshots)
