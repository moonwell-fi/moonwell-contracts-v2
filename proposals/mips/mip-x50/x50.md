MIP-X50: Upgrade xWELL WormholeBridgeAdapter to Wormhole Executor framework

Upgrades WormholeBridgeAdapter on Moonbeam, Base, and Optimism from the
processVAA pattern to the Wormhole Executor framework (V5). The Executor
replaces the deprecated Standard Relayer with a two-step publish + request
execution model, supporting both on-chain quoting (Base, Optimism) and off-chain
signed quotes (Moonbeam, where no on-chain quoter is deployed).
