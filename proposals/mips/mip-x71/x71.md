# MIP-X71: Anthias Labs Risk Parameter Recommendations (10/15/26) and Pause Guardian Migration

## Summary

This proposal implements Anthias Labs' October 15, 2026 risk parameter
recommendations for Moonwell Core markets on Base and OP Mainnet, and moves the
pause guardian role on Base and OP Mainnet to the F-ETH-SEC security council
multisig.

## Base

### Risk Parameter Changes

| Market  | Parameter         | Current | Proposed |
| ------- | ----------------- | ------: | -------: |
| WELL    | Collateral Factor |     45% |      35% |
| VIRTUAL | Collateral Factor |     55% |      50% |
| wrsETH  | Collateral Factor |     42% |      35% |
| AERO    | Collateral Factor |     60% |      58% |
| MORPHO  | Reserve Factor    |     35% |      99% |

### MORPHO Interest Rate Model

| Parameter       | Current | Proposed |
| --------------- | ------: | -------: |
| Base            |       0 |     0.01 |
| Kink            |     0.8 |        0 |
| Multiplier      |  0.0615 |        0 |
| Jump Multiplier |       5 |        0 |

The proposed model targets a simple annual borrow rate of 1% at any utilization.
With a 99% reserve factor, 99% of interest accrual is allocated to reserves.

## Pause Guardian Migration

The pause guardian of the Comptroller and the MultiRewardDistributor on Base and
OP Mainnet is set to F-ETH-SEC (`0x5B710010586C1b728B047c3E42473c700eeA4026`), a
2-of-4 Safe deployed at the same address on Ethereum, Base and OP Mainnet.

| Network    | Contract               | Current                                      | Proposed  |
| ---------- | ---------------------- | -------------------------------------------- | --------- |
| Base       | Comptroller            | `0xB9d4acf113a423Bc4A64110B8738a52E51C2AB38` | F-ETH-SEC |
| Base       | MultiRewardDistributor | `0xB9d4acf113a423Bc4A64110B8738a52E51C2AB38` | F-ETH-SEC |
| OP Mainnet | Comptroller            | `0x355F7b5edbfbfb5cCc7a3C67Dab2f99A72FDDa09` | F-ETH-SEC |
| OP Mainnet | MultiRewardDistributor | `0x355F7b5edbfbfb5cCc7a3C67Dab2f99A72FDDa09` | F-ETH-SEC |

Ethereum's Comptroller, MultiRewardDistributor, xWELL and governor already use
F-ETH-SEC as pause guardian, as does xWELL on Base and OP Mainnet, so no change
is needed there.
