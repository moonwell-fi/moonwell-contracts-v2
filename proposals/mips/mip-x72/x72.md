# MIP-X72: OEV Oracle Wrapper Update

## Summary

This proposal updates Moonwell's Chainlink OEV oracle wrappers on Ethereum,
Base, and OP Mainnet so that early access to a fresh oracle price is limited to
the liquidation that pays for it.

Today, liquidations routed through Moonwell OEV wrappers can make fresh
Chainlink prices available to other liquidations for the remainder of the short
oracle delay window. This allows later liquidations to use the fresh price
without going through the OEV path or contributing the intended OEV fee to the
protocol.

The updated logic keeps the fresh price available for the paying liquidation
only. Once that liquidation is complete, ordinary oracle consumers continue to
see the delayed price until the normal delay window expires.

On Base, it also moves nine Core markets off Chainlink SVR price feeds and onto
the standard Chainlink feeds for the same assets. Chainlink converted the legacy
ETH/USD, BTC/USD, and XRP/USD proxies on Base into SVR proxies. Each SVR proxy
and its standard counterpart read from the same aggregator, so prices are
unchanged.

This proposal does not change collateral factors, liquidation thresholds,
interest rates, OEV fee settings, or supported assets.

## Motivation

Moonwell's OEV system is designed to capture a portion of the value created when
liquidators receive early access to fresh oracle prices. Under the current
implementation, a small liquidation can pay for early access to a fresh price
and unintentionally make that price available to unrelated liquidations. Those
follow-on liquidations can then proceed without contributing the intended OEV
fee.

This proposal closes that gap by limiting the fresh-price unlock to the
individual liquidation that paid for it.

The change preserves the existing OEV design and fee policy while ensuring that
subsequent liquidations seeking early access to the same fresh price must also
use the OEV path.

## Proposal

This proposal will:

1. Redeploy the live Core Chainlink OEV wrappers on Ethereum, Base, and OP
   Mainnet with the updated logic.
2. Repoint the affected Core market oracle feeds to the new wrappers.
3. Preserve each wrapper's existing configuration, including its underlying
   price feed, owner, fee recipient, liquidator fee, maximum round delay, and
   other oracle settings. The exception is the Base ETH/USD, BTC/USD, and cbXRP
   wrappers, whose underlying feed moves from the SVR proxy to the standard
   proxy.
4. Upgrade the existing Base Morpho OEV wrapper proxies for WELL, MAMO, and
   stkWELL in place while preserving their existing configuration and storage.
5. Redeploy the six Base composite oracles that use the ETH/USD or BTC/USD SVR
   proxy as their base feed (cbETH, wstETH, rETH, weETH, wrsETH, LBTC), using
   the standard proxy and keeping their existing exchange-rate feeds, then
   repoint those markets to the new composites.
6. Archive the previous wrapper, composite, and implementation addresses for
   reference.

## Considerations

Because the fresh price is now unlocked only for the paying liquidation, and
only through the wrapper of the collateral being seized, a position that only
becomes liquidatable once a second OEV-wrapped feed is also fresh cannot be
liquidated early through a single wrapper call. Such positions wait until that
feed's delay window expires, after which ordinary liquidation proceeds at the
fresh price. Every wrapper this proposal touches is configured with a maximum
round delay of 10 seconds, so this wait is bounded to 10 seconds per feed, and
the setting remains adjustable by governance.

The Base Morpho market that prices cbETH through the ETH/USD SVR proxy is not
changed: Morpho market oracles are immutable, so moving it would require a new
market.

## Voting Options

- **Yes:** Approve the OEV oracle wrapper updates across Ethereum, Base, and OP
  Mainnet and limit fresh-price access to the liquidation that pays for it.
- **No:** Keep the existing OEV oracle wrapper behavior.
- **Abstain:** Neutral.

## Conclusion

This proposal updates Moonwell's OEV oracle infrastructure so that early access
to fresh Chainlink prices applies only to the liquidation that pays for that
access.

The change preserves existing oracle and market parameters while ensuring
Moonwell's OEV fee policy operates as intended across Core markets on Ethereum,
Base, and OP Mainnet and the affected Base Morpho markets.
